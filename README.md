# Scissors-Rock-Paper-Spock-Lizard-game

This is my version of the "Rock-Paper-Scissors-Spock-Lizarg" game

## Features
- 5 move options
- Tracks wins, draws and losses
- Uses dictionares for logic and win phrases
- Handles incorrect input

## How to run
1. Install Python 3
2. Download the file "rpslsgame.py'
3. run it in the terminal: python rpslsgame.py
