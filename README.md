## English

This is a command-line game where you can choose between:
- Rock
- Paper
- Scissors
- Lizard
- Spock

Features:
- Input validation
- Tracks wins, draws and losses
- Uses dictionares for logic and win phrases
- Clear, readable code(PEP8-friendly)
___

## How to run
1. Install Python 3
2. Download the file "rpslsgame.py'
3. run it in the terminal: python rpslsgame.py 
___
